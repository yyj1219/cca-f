SCENARIO: You are using Claude Code to accelerate software development. Your team uses it for code generation, refactoring, debugging, and documentation. You need to integrate it into your development workflow with custom slash commands, CLAUDE.md configurations, and understand when to use plan mode vs direct execution.

QUESTION: To speed up large refactoring investigations, your team builds a harness with the Claude Agent SDK. A coordinator is defined via AgentDefinition with allowed_tools set to Read, Grep, and Glob, and three subagents are defined with clear descriptions and system prompts: a dependency mapper, a test-gap analyzer, and a documentation writer. The coordinator's system prompt explicitly instructs it to delegate investigation work to these subagents, yet in every test run **it performs all of the file exploration itself(코디네이터는 파일 탐색 전체를 스스로 수행)** and **never spawns a single subagent(단 하나의 서브 에이전트도 생성(호출)하지 않습니다)**. Which configuration change resolves this behavior?

**선택지**:
1. Restate the delegation requirement at the start of the coordinator's system prompt and name each subagent explicitly
2. Add "Task" to the coordinator's allowed_tools so it has a mechanism to spawn its subagents => 정답
3. List each subagent's name directly in the coordinator's allowed_tools so it can invoke them as callable tools
4. Rewrite each subagent's description with concrete example tasks so the coordinator can match work to the right specialist

**설명**:

**문제 구분 포인트, 어려운 표현**:
- explicitly: 명시적으로
- spawns: 생성(호출)
- Restate: 재명시
