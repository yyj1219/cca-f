SCENARIO: You are building a customer support resolution agent using the Claude Agent SDK. The agent handles high-ambiguity requests like returns, billing disputes, and account issues. It has access to your backend systems through custom Model Context Protocol (MCP) tools (get_customer, lookup_order, process_refund, escalate_to_human). Your target is 80%+ first-contact resolution while knowing when to escalate.

QUESTION: The team wants every resolved conversation to produce a machine-readable case record (issue category, resolution type, refund amount if any, escalation flag) for an analytics database. They plan a separate summarization request at the end of each conversation that passes in the transcript, and downstream ingestion breaks whenever the output is conversational text or malformed JSON. Which TWO design decisions correctly apply the tool-based structured output pattern? (Select TWO.)

**선택지**:
1. Mark every schema field, including refund_amount and order_id, **as required** so ingested records are always fully populated for the analytics team
2. Instruct the model in the system prompt to append a JSON summary after its final reply, then pull the object out of the text block with a regex 
3. Define a log_case_summary tool whose input_schema matches the analytics record(분석 레코드와 input_schema가 매칭되는), and parse the record from the tool_use block's input object (tool_use 블록의 input 객치에서) => 정답
4. Set tool_choice to the log_case_summary tool by name so the summarization request must return a schema-conformant record rather than prose => 정답
