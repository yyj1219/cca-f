SCENARIO: You are integrating Claude Code into your Continuous Integration/Continuous Deployment (CI/CD) pipeline. The system runs automated code reviews, generates test cases, and provides feedback on pull requests. You need to design prompts that provide actionable feedback and minimize false positives.

QUESTION: Your team is defining **two subagents via AgentDefinition** for this pipeline: **one reviews pull request** diffs and flags issues, and **the other generates test cases** for changed modules. You want **each subagent to stay focused on its role** while also keeping per-run cost under control. Which two configuration decisions are sound? (Select TWO.)

**선택지**:

1. Grant both subagents the **full built-in tool** set and use system prompt instructions to keep the review agent from ever writing files
2. **Set the model field per AgentDefinition**, running high-volume test generation on a faster, cheaper model while review uses a more capable one => 정답
3. **Give each subagent its own tailored system prompt**, encoding severity criteria for the review agent and test-writing conventions for the generation agent => 정답
4. Rely on each subagent **inheriting** the coordinator's system prompt and conversation history so review standards defined once apply to both automatically

**설명**:
- 복잡한 추론과 코드 분석이 필요한 PR 검토 작업에는 성능이 뛰어난 고성능 모델(예: Claude 3.5 Sonnet 등)을 할당하고, 패턴이 정형화되어 있고 수량이 많은 대량의 테스트 케이스 생성 작업에는 상대적으로 가볍고 빠른 모델(예: Claude 3.5 Haiku 등)을 지정함으로써 전체 파이프라인의 실행 비용(per-run cost)을 크게 절감할 수 있습니다.
- 서브에이전트가 자신의 역할에 명확히 집중하도록 하려면 역할별 맞춤형 시스템 프롬프트(Tailored System Prompt)를 명시해야 합니다.

**문제 구분 포인트, 어려운 표현**:
- AgentDefinition
- severity criteria: 심각도 기준
