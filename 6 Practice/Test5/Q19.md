SCENARIO: You are building a structured data extraction system using Claude. The system extracts **information from unstructured documents**, validates the **output** using JavaScript Object Notation **(JSON) schemas**, and maintains high accuracy. It must handle edge cases gracefully and integrate with downstream systems.

QUESTION: The system's coordinator handles requests such as "extract all payment-related provisions from this supplier contract." Logs show that for every such request, the coordinator decomposes the work into **three parallel subagent tasks**: invoice due dates, late-payment penalties, and early-payment discounts. All three subagents complete successfully, **and inspecting their outputs shows** each contains accurate structured data for its assigned category and nothing else. Yet the final merged records **consistently omit** currency-conversion clauses, escrow requirements, and payment-method restrictions that reviewers confirm are present in the source contracts. Which change most effectively eliminates the missing provisions?

**선택지**:

1. Reorder the aggregated subagent outputs so critical provisions appear at the start and end of the combined input the synthesis model receives => 이미 누락된 걸 재배치해도 소용없다
2. Rewrite the synthesis subagent's prompt to enumerate **the complete list of expected provision types** so no fields are dropped during merging => 이미 누락된 건 전체 목록 나열해도 소용없다
3. **Broaden the coordinator's decomposition** to cover all payment-related provision categories, **adding a catch-all subtask** for uncategorized provisions => 정답. 누락을 막는 작업을 추가한다
4. **Update** each extraction **subagent's output schema** to mark the missing provision types as required fields so the model cannot silently omit them => 오답. 누락된 조항에 스키마 강화는 소용없다

**설명**:
- 전체 지급 관련 조항을 하나의 요청으로 묶었지만, 이를 세 가지 작은 태스크로 나누면서 일부 조항이 빠지거나 누락되는 문제
- 코디네이터의 (작업) 분할 범위를 넓힌다
- 코디네이터는 "지급 관련 모든 조항"을 하나로 묶는 대신, 더 세분화하거나, 또는 빠진 조항들이 전체 범위에 포함되도록 새로운 '포괄적인' 태스크를 추가하는 겁니다. 

**문제 구분 포인트, 어려운 표현**:
- consistently omit: 지속적으로 누락
- Broaden the coordinator's decomposition: 코디네이터의 (작업) 분할 범위를 넓힌다
- adding a catch-all subtask: 포괄적(catch-all) 하위 태스크 추가
