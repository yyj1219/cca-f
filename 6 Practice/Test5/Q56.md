SCENARIO: You are building a structured data extraction system using Claude. The system extracts information from unstructured documents, validates the output using JavaScript Object Notation (JSON) schemas, and maintains high accuracy. It must handle edge cases gracefully and integrate with downstream systems.

QUESTION: The system routes low-confidence field extractions to a human review queue for verification before downstream delivery. Reviewers have no access to the model's session and see only the queue record, which currently names the flagged field and nothing else. Reviewers report that verifying a single flagged value takes about ten minutes because they must open and re-read the full 40-page source document to find where the value came from. What change most effectively reduces this verification effort?

**선택지**:
1. Raise the confidence threshold for routing so fewer extractions reach the queue and total reviewer time drops accordingly
2. Embed the complete raw text of the source document in each record so reviewers never have to locate or open the original file
3. **Include the extracted value**, the source excerpt it was drawn from with document and page location, and the reason it was flagged
4. Include only the field name and its **confidence score** so reviewers verify against the source without anchoring on the model's output

**설명**:
- 검토에 필요한 최소한의 맥락과 근거 위치 정보(Provenance)를 대기열 레코드에 함께 제공하기
- 레코드에 "추출된 값", "값이 추출된 원본 구절(Excerpt) 및 페이지 위치 정보(Page location)", "플래그가 지정된 이유(낮은 신뢰도 원인)"를 함께 전달한다

**문제 구분 포인트, 어려운 표현**:
- excerpt: 발췌
- drawn from: ~에서 가져온
