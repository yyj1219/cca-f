SCENARIO: You are using Claude Code to accelerate software development. Your team uses it for code generation, refactoring, debugging, and documentation. You need to integrate it into your development workflow with custom slash commands, CLAUDE.md configurations, and understand when to use plan mode vs direct execution.

QUESTION: Your team's custom slash command pipes changed code into a script that calls the Messages API with three documentation tools defined: document_function, document_class, and document_module, each with a distinct input schema. The type of each code change is unknown in advance, so the model must **pick the appropriate schema itself**, and the downstream formatter fails whenever a response contains prose instead of a tool_use block. In testing, some responses **arrive as plain text** explanations. Which change makes every response arrive as a tool call while still letting the model select the right documentation schema?

**선택지**:
1. Set tool_choice to {"type": "auto"} and add a system prompt instruction stating that a tool must be called on every request
2. Set tool_choice to **{"type": "any"}** so a tool invocation is compelled but the model chooses among the three tools => 정답
3. Leave tool_choice unset and add a validation step that detects prose responses and resubmits the request until a tool call appears
4. Set tool_choice to {"type": "tool", "name": "document_module"} so the response always contains a predictable tool_use block

**설명**:
- Anthropic Messages API에서 도구 사용(Tool Use)을 제어하는 tool_choice 파라미터
  - {"type": "auto"}: 기본값. 모델이 도구를 호출할지, 일반 텍스트(prose)로 응답할지 스스로 판단
  - {"type": "any"}: 모델이 반드시 하나 이상의 도구를 호출
  - {"type": "tool", "name": "..."}: 지정한 특정 도구 하나만 반드시 호출
