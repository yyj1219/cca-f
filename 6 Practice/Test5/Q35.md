SCENARIO: You are building a structured data extraction system using Claude. The system extracts information from unstructured documents, validates the output using JavaScript Object Notation (JSON) schemas, and maintains high accuracy. It must handle edge cases gracefully and integrate with downstream systems.

QUESTION: The pipeline's per-document extraction already emits each field value together with the document name and page it came from. The consolidation step then merges records across documents, and when the same value appears in several documents it keeps a single attribution, whichever document it encountered first. Last month one scanning batch was found to contain OCR corruption, and every consolidated record attributing any field to those documents had to be pulled for full re-review, even though many of the affected values also appeared in clean documents; the records gave no way to tell which values had independent support. Which change to the consolidation step fixes this?

**선택지**:
1. Append a bibliography listing every input document to each consolidated record so auditors can see all sources consulted => 참고문헌 목록만 가진 상태로는 해당 값이 어떤 문서들에서 비롯된 것인지를 파악할 수 없어서 오답
2. Have consolidation merge **attribution lists** so **each field value** retains **every source** document that supported it => 정답
3. Replace per-value attributions with a count of supporting documents so consolidation output stays compact
4. Rank candidate sources by extraction confidence and attach only the highest-confidence document to each merged value

**설명**:
통합 단계에서 각 값이 어떤 문서들로부터 왔는지 출처를 포함하는 방법

**문제 구분 포인트, 어려운 표현**:
- high accuracy: 높은 정확도
- emits: 배출(출력)
- consolidation: 통합
- single attribution: 하나의 귀속(출처)
- encountered: 발견된
- corruption: 오염(인식 오류)
- attributing any field: 임의의 필드가 귀속된
- attribution lists: 출처 목록
- bibliography: 참고문헌/출처목록
- confidence: 신뢰도
