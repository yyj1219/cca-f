SCENARIO: You are building a structured data extraction system using Claude. The system extracts information from unstructured documents, validates the output using JavaScript Object Notation (JSON) schemas, and maintains high accuracy. It must handle edge cases gracefully and integrate with downstream systems.

QUESTION: Your extraction pipeline uses a coordinator agent built with the Claude Agent SDK. The coordinator parses a lengthy contract, produces a draft JSON extraction, and holds the target schema in its conversation from an earlier tool result. It then **delegates to a non-fork validation subagent** with the prompt "Validate the extracted fields against our schema," and the subagent responds that it has no fields or schema to work with. Which two changes should the architect make to the coordinator-to-subagent handoff? (Select TWO.)

**선택지**:
1. Move the target schema into the coordinator's system prompt so the subagent automatically receives it at invocation time.
2. Instruct the validation subagent to return a concise structured validation result as its final message to the coordinator. => 정답
3. Embed the draft extraction JSON and the target schema directly in the delegation prompt when invoking the validation subagent. => 정답
4. Add an instruction telling the subagent to reference the coordinator's earlier conversation turns where the schema tool result appeared.

**설명**:
- 독립된 서브에이전트는 위임 호출 시 전달하는 프롬프트(delegation prompt) 자체에 검증 대상인 초안 추출 JSON과 목표 스키마를 직접 텍스트나 페이로드로 포함하여(Embed) 명시적으로 전달해야만 서브에이전트가 이를 받아 작업을 수행할 수 있습니다.
- 서브에이전트가 검증을 끝낸 후 결과를 상위 코디네이터 에이전트에게 돌려줄 때, 간결하고 구조화된 형태(Concise structured validation result)로 응답하도록 지시하는 것이 핸드오프(Handoff) 설계의 베스트 프랙티스입니다.

**문제 구분 포인트, 어려운 표현**:
- concise: 간결한
