SCENARIO: You are building a structured data extraction system using Claude. The system extracts information from unstructured documents, validates the output using JavaScript Object Notation (JSON) schemas, and maintains high accuracy. It must handle edge cases gracefully and integrate with downstream systems.

QUESTION: The extraction pipeline's CI step feeds each document to Claude Code with the pattern cat document.txt | claude -p "extract the fields defined in the schema". Most documents process fine, but **one 25 MB contract dump** causes the step to exit **immediately with an error** message and a non-zero status on every run. What is the recommended fix?

**선택지**:
1. Switch to --output-format stream-json so the document is delivered in newline-delimited chunks rather than one payload
2. Drop the -p flag for oversized documents so an interactive session can accept the full content without the print-mode limit
3. Wrap the step in retry logic with exponential backoff, since the immediate failure indicates a transient pipe error
4. **Write the oversized document to a file** in the workspace and reference **its path in the prompt** instead of piping the content => 정답

**설명**:
